# 全站表单与危险操作弹窗设计

日期：2026-11-20

## 1. 目标与范围

将当前前端新增、编辑、删除、重置密码及其他危险确认从内联或吸附式展示统一改为居中悬浮弹窗。视觉采用用户选择的「A · 悬浮工作台」：轻遮罩、圆角卡片、清晰层级、顶部细节 accent、底部固定操作区，兼顾复杂长表单和简单危险确认。

覆盖作者、单位、作者授权、期刊、稿件、用户、注册任务及其取消/撤销确认。筛选器、只读详情和证据抽屉保持现状。现有表单字段、角色权限、输入校验、幂等键、API 请求、错误请求 ID 和成功提示保持不变，不修改后端接口或数据库，不新增前端依赖。

## 2. 方案比较与选择

### 采用：共享 AppModal 与 AppConfirmDialog

基于项目已有 Element Plus `ElDialog` 封装统一组件，按选定视觉方向定制。利用成熟组件的 Teleport、焦点管理、键盘交互和滚动锁定，页面只保留业务表单和状态。

### 不采用：完全自研 Modal

视觉自由度高，但需要自行实现焦点循环、Esc、滚动锁定、屏幕阅读器支持和边界测试，重复工作及维护成本较高。

### 不采用：各页面直接散落使用 ElDialog

初始改动较少，但宽度、按钮、错误展示、未保存修改保护和危险确认容易再次不统一。

## 3. 组件职责

### AppModal

承载新增、编辑和重置密码等表单，提供：

- `title`、`description`、`width`、`busy`、`dirty` 等统一属性；
- 标题、说明、默认内容、错误区域和底部操作区；
- 标准与宽表单两种桌面尺寸，移动端接近全宽；
- 弹窗内部滚动、页面滚动锁定和减少动画偏好支持；
- 正确的 `role="dialog"`、`aria-modal`、标题关联、焦点循环和关闭后的焦点返回。

### AppConfirmDialog

承载软删除、撤销授权、取消任务等危险操作，提供：

- 危险级别图标、标题、影响范围和后果说明；
- 取消按钮、危险按钮及执行中加载状态；
- 现有显式确认勾选的统一承载，执行前必须完成确认；
- 失败时保留确认上下文，禁止重复执行。

### useDirtyGuard

跟踪表单初始快照与当前值，判断是否存在未保存修改。新增表单以空值或默认值为基线，编辑表单以加载完成的数据为基线，保存成功后重置基线。

## 4. 交互与异常处理

### 打开与关闭

- 点击操作后先加载或初始化数据，再打开弹窗；第一个可编辑字段获得焦点。
- 支持标题栏关闭、取消按钮和 Esc；遮罩点击默认不关闭。
- 有未保存修改时，关闭需要再次确认“放弃未保存的修改？”；无修改时直接关闭。
- 提交中禁止关闭和重复提交，嵌套的放弃修改确认层级高于当前表单。

### 成功与失败

- 保存成功后才关闭弹窗并显示现有成功提示，同时重置未保存状态。
- 保存失败时弹窗保持打开，错误和请求 ID 显示在弹窗内部，保留用户输入。
- 数据加载失败时不打开空白表单，在原页面展示可重试错误。

### 危险操作

- 删除、撤销和取消任务使用独立 `AppConfirmDialog`，明确影响范围与后果。
- 保留现有显式确认勾选，不以单击危险按钮替代确认。
- 执行期间显示加载状态并禁止重复操作，失败后保留确认上下文。

## 5. 视觉与响应式

- 使用轻量深色遮罩和克制的背景模糊，避免过度炫技。
- 卡片采用圆角、细边框、柔和阴影和顶部蓝绿 accent。
- 标题、说明、正文和底部操作区层级清晰，底部操作区在滚动时保持可用。
- 桌面端复杂表单使用宽弹窗，简单表单使用标准弹窗，不强制全屏。
- 移动端使用近乎全宽布局，按钮可换行，复杂表单在弹窗内部滚动。
- 尊重减少动画偏好，避免大幅位移和闪烁。

## 6. 文件与迁移顺序

新增：

```text
frontend/src/components/AppModal.vue
frontend/src/components/AppConfirmDialog.vue
frontend/src/components/AppModal.test.ts
frontend/src/components/AppConfirmDialog.test.ts
frontend/src/composables/useDirtyGuard.ts
```

在 `frontend/src/style.css` 增加共享弹窗样式和响应式规则。

迁移顺序：

1. 共享组件、未保存修改保护和组件测试。
2. 作者、单位、作者授权和用户页面。
3. 期刊与稿件页面。
4. 注册任务及取消/撤销确认。
5. 检查并移除残留的内联 `stacked-form` 与 `confirmation-panel`，完成全量回归和浏览器检查。

`scripts/启动说明.md` 与 `aaa.word` 不属于本次修改范围。

## 7. 测试与验收

### 组件测试

- 弹窗打开、关闭、标题关联和底部按钮行为。
- 无修改直接关闭，有修改二次确认，提交中禁止关闭。
- 危险操作必须显式确认，执行中禁止重复操作。
- 失败时保留弹窗、输入和确认上下文。

### 页面测试

逐页验证：

1. 点击新增/编辑/危险操作后出现对应弹窗。
2. 填写或确认后调用原有 API 和原始参数。
3. 成功后弹窗关闭并刷新数据。
4. 失败后弹窗不关闭且错误可见。
5. 权限、校验、幂等键和显式确认行为不回归。

### 完整验证

- 全部 Vitest 测试和覆盖率检查。
- TypeScript 检查及 Vite 生产构建。
- 项目完整 `scripts/verify.sh`，确保后端与 API 契约不受影响。
- 实际浏览器检查桌面与移动宽度下的布局、键盘交互和滚动行为。
