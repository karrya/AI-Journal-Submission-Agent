现在启动后端和两个 Worker，只需要：
     
  bash scripts/dev_services.sh start

  它会启动：

  - FastAPI 后端
  - 网络识别 Worker
  - 注册 Worker

  前端仍需单独启动：

  bash scripts/dev_frontend.sh

  如果 MySQL 尚未运行，先执行：

  brew services start mysql@8.0

  其他常用命令：

  bash scripts/dev_services.sh status   # 查看状态
  bash scripts/dev_services.sh restart  # 重启所有后台服务
  bash scripts/dev_services.sh stop     # 停止所有后台服务
